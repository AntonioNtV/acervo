# HTTP API

FastAPI, created by `create_app()` in `api/main.py`. Every route is under `/v1` and every route but `/v1/health`
requires `X-API-Key` (the value of `API_KEY`, never empty); health is open on purpose, the compose healthcheck calls
it. The raw, cover and export routes also take a signed link, so the key never appears in a URL. The OpenAPI document it produces is
committed as `docs/openapi.json` and generates the web app's types; no path string lives in the web app outside the
generated client. Exemplar: `api/routers/nodes.py`.

| Piece | File |
|---|---|
| app factory and lifespan (engine, session factory, `Storage`), CORS | `api/main.py` |
| dependencies: settings, storage, `UnitOfWork`, services, `require_api_key` | `api/deps.py` |
| `AcervoError` and `RequestValidationError` → `ErrorResponse` | `api/errors.py` |
| one router per resource | `api/routers/{health,kbs,nodes,trash,files,pages,favorites,covers,exports}.py` |
| request/response models, `ErrorResponse` | `schemas/*.py` |
| export | `scripts/export_openapi.py` → `docs/openapi.json` |
| web client | `web/src/api/schema.gen.ts`, generated by `pnpm gen:api` |

## Rules

- **Routers hold no logic.** Validate, call one service method, return its result. A router never imports `db/`,
  `repositories/` or `pipeline/`.
- **Models:** `XRequest` / `XResponse` (and the entities' `XRead`) in `schemas/`. Every field has
  `Field(description=...)` and every model a docstring: they are the OpenAPI the client is generated from.
- Every route sets `response_model` (or `status_code` for 204) and declares every non-2xx status in `responses=`
  with `ErrorResponse`. A literal segment (`/kbs/trash`) goes before a `{id}` that would swallow it.

## Routes

| Method and path | Does |
|---|---|
| `GET /v1/health` | liveness, no key on purpose (the compose healthcheck) |
| `GET /v1/kbs?q=` · `POST /v1/kbs` · `PATCH /v1/kbs/{kb_id}` | list (with counts and last edit), create, rename, describe or set the icon of bases |
| `DELETE /v1/kbs/{kb_id}` · `GET /v1/kbs/trash` · `POST /v1/kbs/{kb_id}/restore` | a base to the global trash and back |
| `GET /v1/kbs/{kb_id}/children?parent_id=` | one folder's children in the person's order; files carry `protected` |
| `GET /v1/kbs/{kb_id}/search?q=` | title search (⌘K), ignoring case and accents, with each hit's path |
| `GET /v1/kbs/{kb_id}/trash` | the base's trashed items, with where they were |
| `POST /v1/kbs/{kb_id}/nodes` | a folder or a page; a page gets its first version |
| `GET /v1/nodes/{node_id}` · `PATCH /v1/nodes/{node_id}` | a node with its path; rename (a page rename fixes the `[[…]]` links to it), description, icon, cover |
| `POST /v1/nodes/{node_id}/move` | into a folder or a page of the same base or of another (`kb_id`), before a sibling or last |
| `POST /v1/nodes/{node_id}/duplicate` | a copy of a page with its sub-pages, right after it; files are not copied |
| `DELETE /v1/nodes/{node_id}` · `POST /v1/nodes/{node_id}/restore` | to the trash with its subtree, and back (`to_root`) |
| `GET /v1/pages/{node_id}` | a page's current text (working text, else the newest version), `revision`, `saved_at`, links and sections |
| `PUT /v1/pages/{node_id}/text` | autosave the working text with the `revision` it read (`stale_page` with the newest `markdown` and `revision`; the refused text is kept as a version) |
| `POST /v1/pages/{node_id}/leave` | cut a version from the working text now (no-op when unchanged) |
| `GET /v1/pages/{node_id}/mentions` | the pages linking to this one, each with the line holding the link |
| `GET /v1/pages/{node_id}/versions` · `…/versions/{version_id}/diff` · `…/versions/{version_id}/restore` | history, diff against the version before, restore as a new version |
| `POST /v1/kbs/{kb_id}/files` | multipart `file` and `parent_id`: a file into a folder or a page; `duplicate` with its path |
| `POST /v1/nodes/{node_id}/file` | replace a file; the current content goes to its history (`same_file` when identical) |
| `GET /v1/files/{node_id}/versions` · `POST /v1/files/{node_id}/versions/{version_id}/restore` | a file's older contents, and restoring one |
| `GET /v1/files/{node_id}/raw?version_id=` | the original bytes, one `Range` honored (open-ended too), under the original file name |
| `POST /v1/files/{node_id}/link?version_id=` | `{url, expires_at}`: the raw route with `expires` and `signature` (HMAC-SHA256 with the key over node, version and expiry, `core/signing.py`), valid 60 s; the raw route takes it instead of the header for exactly that node and version |
| `GET /v1/favorites` · `PUT /v1/nodes/{node_id}/favorite` · `DELETE /v1/nodes/{node_id}/favorite` | the favorites of every base, in their order, with paths; add or reorder one (`before_id`), remove one |
| `POST /v1/nodes/{node_id}/cover` · `…/cover/link` · `GET …/cover/raw` | upload a PNG, JPEG or WebP cover (at most `cover_max_bytes`) for a folder or page; a signed link to it; the image |
| `POST /v1/nodes/{node_id}/export/link` · `GET /v1/nodes/{node_id}/export` | a signed link; the zip of a page or folder and everything live under it, made as it is sent |

## Errors

Every error body is `ErrorResponse {error, message, details}`. The web app shows text by `error` (the code), never
the raw `message`.

| Error (`core/errors.py`) | Status | `error` code |
|---|---|---|
| `NotFoundError` | 404 | `not_found` |
| `ConflictError` | 409 | `conflict` |
| `TitleTaken`, `Duplicate`, `StalePage`, `SameFile` | 409 | `title_taken`, `duplicate`, `stale_page`, `same_file` |
| `ValidationError` | 422 | `validation` |
| `AuthError` | 401 | `unauthorized` |

The status is looked up along the error's MRO in `api/errors.py`, so a subclass with its own code keeps its
parent's status. FastAPI's own `RequestValidationError` is answered 422 with the same shape. Never return a bare
dict. A new code is a subclass only when a screen must tell it apart.

## Adding a route

1. The behavior is a service method, tested at the service (skill `testing`).
2. Request/response models in `schemas/<resource>.py`, with descriptions and docstrings.
3. The route in `api/routers/<resource>.py` with `dependencies=[Depends(require_api_key)]` on the router.
4. A test in `tests/api/` for the success path and each error code.
5. `make openapi` regenerates `docs/openapi.json` and `web/src/api/schema.gen.ts` in the same delivery; CI fails
   when either is stale.
