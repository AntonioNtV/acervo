# Contract

FastAPI serves the routes; the OpenAPI document it produces generates the web app's types and client. No path
string lives in the web app outside the generated client.

| Piece | File | What it is |
|---|---|---|
| routes | `api/routes.py` | one function per route, thin: parse, call the concept, return a model |
| models | `api/models.py` | `*Request` / `*Response` Pydantic models and `ErrorResponse` |
| events | `api/events.py` | websocket event models: `job.progress`, `proposal.created`, `proposal.updated`, `nav.step`, `answer.delta` |
| schema | `acervo contract schemas` | prints the OpenAPI 3.1 document, events included as components |
| web client | `web/src/api/schema.gen.ts` | generated by `pnpm gen:api` |

## Routes

| Method and path | Does |
|---|---|
| `GET /kbs` · `POST /kbs` | list, create bases |
| `GET /kbs/{kb_id}/tree` | the node tree with descriptions |
| `GET /nodes/{node_id}` · `PUT /nodes/{node_id}` | read a page or a PDF's metadata; save a page edit |
| `GET /nodes/{node_id}/versions` | page or file history |
| `GET /files/{node_id}/raw` | the original PDF bytes |
| `POST /kbs/{kb_id}/files` | upload a PDF to staging; starts intake |
| `POST /kbs/{kb_id}/chat` | a message in Capturar or Perguntar; progress and answer come by websocket |
| `GET /kbs/{kb_id}/proposals` | with `status` |
| `POST /proposals/{id}/accept` | optional edited payload |
| `POST /proposals/{id}/reject` | `reason` required |
| `POST /proposals/{id}/alternative` | swap to the second path |

## Errors

| Error (`errors.py`) | Status |
|---|---|
| `ValidationError` | 400 |
| `NotFoundError` | 404 |
| `ConflictError` (stale version, duplicate PDF) | 409 |
| `ForbiddenOperation` (e.g. writing a PDF's content to a page) | 422 |
| `DecisionUnavailable` (Jev and fallback down) | 503 |

Each is an `AcervoError` with `status` and `to_response()`; one handler maps them all.

## Adding a route

1. The behavior lives in its concept and is tested there (skill `testing`).
2. Models in `api/models.py`; every field has `Field(description=...)`, every model a docstring.
3. The route in `api/routes.py`; a literal segment before a `{id}` that would swallow it.
4. `uv run pytest tests/api`, then `pnpm gen:api` in `web/` in the same delivery.
